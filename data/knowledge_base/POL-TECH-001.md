# Outages and Performance Problems

## Status page
Current incidents and outages are published on the Acme Cloud status page at status.acmecloud.example. Customers should check it before reporting a service problem.

## Production outage
A report that production is down or that many users are affected is escalated to the on-call incident manager immediately. Collect the time the problem started, the affected region and any request IDs.

## Slow performance
For slow dashboards or slow pages, ask the customer to try another browser, clear the cache and note the time of the slowdown and the region. If the problem continues for more than 1 hour, support opens a ticket with engineering.
