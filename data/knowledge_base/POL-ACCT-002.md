# Password Reset and Multi-Factor Authentication

## Password reset
A password reset link is valid for 60 minutes. If the email does not arrive, check the spam folder and confirm the address is the registered one, then request a new link. If the link says it has expired, request a new one and use it within 60 minutes. Only the newest link works.

## Lost multi-factor device
Customers who lost their authenticator device should sign in with a backup code. Without a backup code, support verifies identity with the registered email and the number of the most recent invoice. A support lead then disables multi-factor authentication so the customer can set it up again.

## Never share credentials
Support never asks for a password or a full verification code.
